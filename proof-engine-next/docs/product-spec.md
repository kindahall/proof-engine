# Product Spec

Proof Engine aide les fondateurs de SaaS a transformer leurs preuves terrain en
une experience commerciale mesurable.

## Utilisateurs

- Fondateurs de micro-SaaS.
- Petites equipes produit.
- Produits multi-acteurs avec plusieurs rôles utilisateur.

## Parcours MVP

1. Decrire le produit.
2. Connecter une source read-only ou un Gateway de production.
3. Synchroniser les evenements.
4. Confirmer le mapping source -> evenement canonique.
5. Calculer les metriques et la qualite de donnees.
6. Generer un diagnostic fonde sur preuves.
7. Generer une experience prioritaire.
8. Suivre les resultats synchronises.
9. Cloturer et produire un apprentissage.

## Hors perimetre

Facturation Proof Engine, publication automatique de campagnes, scraping,
embeddings, ecriture dans les backends analyses.

Les connecteurs et Gateway mock sont reserves aux tests internes et au
developpement local.
